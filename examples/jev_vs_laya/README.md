# Jev vs Laya on the same labelled set

This example certifies one labelled dataset on two backends and prints the
coverage of each side by side at a given α.

> **The data is synthetic.** `triage.jsonl` has 400 support tickets generated by
> `make_data.py` from templates with a fixed seed. Every row has
> `"synthetic": true`, names come from a made-up list, and every email is on
> `example.com`. There is no real customer data in it.

## Offline

```bash
python examples/jev_vs_laya/run.py --fake
```

This uses two simulated backends with different skill and calibration. It needs
no network and no keys.

## Live

```bash
export TYPESAFE_API_KEY=...            # sent only to https://api.typesafe.ai
laya-serve &                           # from `pip install laya`, on :8000
python examples/jev_vs_laya/run.py --laya-url http://localhost:8000 --laya-model <pinned model>
```

## Files

| File | What it is |
|---|---|
| `questions.json` | Three questions: `department` (choice), `urgency` (score 0–3), `is_refund` (noul). |
| `triage.jsonl` | `{"id", "synthetic", "state", "labels"}` rows, ready for `surety collect`. |
| `make_data.py` | Regenerates `triage.jsonl` byte for byte. |
| `run.py` | Collects from both backends, certifies with `--simultaneous`, and prints the table. |

Expect different thresholds and coverage per model. A threshold certified for one
model says nothing about another, even on the same data.
